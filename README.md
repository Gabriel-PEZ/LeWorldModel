# LeWorldModel

**Work in Progress**

PyTorch reimplementation of LeWorldModel, a JEPA-based world model for learning visual representations, predicting latent dynamics, and planning actions using Model Predictive Control (MPC).

**Reference paper :** [LeWorldModel: Stable End-to-End Joint-Embedding Predictive Architecture from Pixels](https://arxiv.org/abs/2603.19312).

This project is part of the Robotics course of the MVA Master's program (ENS Paris-Saclay).

Implementation and experiments are currently in progress.
